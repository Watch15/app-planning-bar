01 Templyo

Le planning d’un groupe de bars et restaurants

Templyo s’adresse au patron (ou à la direction) qui gère plusieurs adresses CHR avec une équipe. Une seule application pour collecter les dispos, construire la semaine, la publier, pointer les heures réelles et lire la masse salariale face au CA.

Le besoin

Quand l’équipe tourne entre plusieurs établissements, le planning sort des tableurs et des groupes de discussion. Les adresses se marchent dessus, les trous se voient trop tard, et les heures réellement faites ne recoupent pas ce qui était prévu. Le second levier de rentabilité CHR, après le CA, reste opaque : la masse salariale.

Ce que fait Templyo

L’équipe déclare depuis le téléphone. Le patron valide, pose les gens (et les Jokers) établissement par établissement, puis publie : tant que la semaine n’est pas publiée, personne de l’équipe ne la voit. Les journées, un code à 4 chiffres sert à pointer le début et la fin. Ces heures réelles alimentent le coefficient masse chargée / CA, adresse par adresse.

Comment on s’en sert

  1. 1Dispos. L’équipe indique où et quand elle peut travailler.
  2. 2Planning. Le patron construit la grille, puis publie la semaine.
  3. 3Joker. Un poste sans titulaire reste visible ; le staff peut postuler.
  4. 4Téléphone. Chacun voit uniquement les semaines publiées.
  5. 5OTP. Le responsable dicte un code ; début puis fin sont pointés.
  6. 6Pilotage. CA, masse chargée, coefficient par établissement.

Les écrans suivants sont une maquette statique, avec des données d’exemple (groupe fictif de 8 établissements). Ce n’est pas une démonstration connectée.

06 Pointage

Un code à 4 chiffres, début puis fin
