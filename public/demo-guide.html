2. Parcours recommandé

Comptez ~30 minutes pour le tour complet. Chaque carte = un moment à laisser digérer.

A · Le cycle cœur — compte patron

1Planning · semaine en cours
Semaine publiée. Basculez Zinc ↔ Rotonde : la grille suit les horaires.
2Filtrer par groupe
Bar / Salle / Cuisine. Les polyvalents sans groupe restent visibles partout.
3Semaine suivante = brouillon
File de dispos → valider → publier. C’est le cœur du produit.
4KPI Dispos envoyées
Pas à 100 % : montrez la relance.

B · Les rôles

5Directrice
Un seul établissement, un seul récap.
6Observateur
Voit Planning / Performance, pas Dispos / Échanges.

C · Terrain & pilotage — revenir en patron

7Pointage
Code OTP + clôture du jour (Début manuel, Ajuster, journal). Comparer planifié / réel.
8Performance · Réel
CA, masse, coefficient contre l’objectif.
9Performance · Simulation
Jour ou semaine, sans écrire le CA officiel.
10Récap mensuel
Heures, écarts, Excel.

D · Options & vie d’équipe

11Joker ouvert — candidatures, en retenir une.
12Échanges — une demande attend votre validation.
13Congés — demande, refus, staff grisé au planning.
14Gestion du staff — taux, groupes, archivée (historique conservé).

3. Mode d’emploi rapide

Construire une semaine

  1. Choisir l’établissement (onglets).
  2. Glisser le personnel, ou copier une semaine type.
  3. Poser des Jokers pour les postes à pourvoir.
  4. Publier quand la grille est bonne — sinon l’équipe ne voit rien.

Collecter les disponibilités

  1. Ouvrir la saisie des dispos (horizon réglable).
  2. L’équipe répond depuis son téléphone.
  3. Valider dans la file, puis placer les gens sur le planning.

Pointer les heures

  • Code : le responsable dicte le code 4 chiffres ; début puis fin.
  • Saisie directe (tablette de l’établissement) : cartes d’heures, sans panneau de clôture.

Les heures réelles alimentent le récap et la Performance.

Piloter

Menu Performance : CA du soir, coefficient, simulation d’une semaine à venir.
